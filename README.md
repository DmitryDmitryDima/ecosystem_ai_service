# AI Service

Сервис находится в зародышевом состоянии. По плану он будет предоставлять доступ к llm для нуждающихся в нем компонентов системы. По задумке он будет получать готовый шаблон prompt'а. Шаблон prompt'а может содержать не только сырой текст, но и данные относительно формата ожидаемого ответа от LLM, специальные команды, необходимые для "дозаполнения" запроса, и т.д. То есть суть в том, что сервис - исполнитель команд, а не точка принятия решения. Выделение AI в отдельный микросервис обусловлено тем, что запросы к llm - нестабильны по времени и результату, из-за чего логика работы с ними должна быть event-based.
